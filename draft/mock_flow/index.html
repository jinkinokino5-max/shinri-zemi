見るときの注意

  • ・写真は0枚です。色つきの絵は CSS で描いた仮のもので、実写ではありません。 実写が入るまで最終的な見え方は確定しません。
  • ・写真が入った状態と入っていない状態を同時に見られるよう、 21件のうち一部だけ写真枠を出しています。実際にはいま全件が「写真なし」です。
  • ・帯はマウスを乗せると止まります（読みたい人が読めるように）。
  • ・OSの「視差効果を減らす」を入れると、全案が静止して全21件が読める形に落ちます。 単に止めるだけだと帯の半分が画面外に残って情報が消えるため、 折り返しまで指定しています。
  • ・案08だけ「一時停止」ボタンがあります。5秒以上自動で動くものは 利用者が止められなければならないため（WCAG 2.2.2）、装飾ではなく要件です。
  • ・合体案（02×04）の背景に流れる名前は装飾で、読ませる対象ではありません。 コントラストを意図的に落とし、リンクにもしていません。 同じ21件は必ず下の写真の帯にも出しているので、情報は失われません。

合体案について（02 × 04）

  • ・題字を小さくせずに解決しています。現行トップの欠点は1画面目が題字だけで 「何をしている団体か」が分からないことでしたが、 題字を縮めるのではなく、その背後と直下に活動そのものを置く形にしました。
  • ・題字は文字が抜けている形なので、「心」「理」の内側を背景の名前が通り抜けて見えます。 これは意図した効果です。ただし字が潰れては本末転倒なので、 背景色は生成りとの差が小さい値に固定しています。ここを濃くしないでください。
  • ・⚠ 動く要素は背景3本＋写真の帯1本＝4本で、 大本資料 8-4「1画面に同時に動く要素は3つまで」を1つ超えています。 上限超過を承知のうえで3列を選択したものです。 実機でうるさく感じたら、最初に戻すのはここ（背景を2本にすれば上限内）。
  • ・背景の文字は3列にしたぶん一段小さくしてあります（最大 88px → 64px）。 88px のまま3列にすると縦が溢れ、題字に文字が貼り付いて汚れに見えます。 大きくするなら、ヒーローの高さも一緒に上げる必要があります。
  • ・画面幅 1000px 以下で3本目、760px 以下で2本目を落とします。 幅が狭まると1本あたりの文字数が減り、そのままでは密度が高くなりすぎるためです。
