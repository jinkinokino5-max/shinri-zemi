## 0. 10案の作り方（この資料の骨格）

10案は思いつきではなく、**MVVの語句を1つずつ、画面の構造そのものに翻訳したもの**である。

| 案 | 翻訳した語句 | 出典 |
|---|---|---|
| 1 目録 | 「妄想の**目録**」＋原理1 | 大本資料 コンセプト |
| 2 溢れる | 大学生の**溢れ出す**妄想を形にする | Mission |
| 3 整列 | 溢れ出す妄想を**形にする** | Mission |
| 4 図面 | 妄想を**形にする**（＝設計する） | Mission |
| 5 物量 | 北大で**最も大量に** | Vision |
| 6 落差 | **おもろい**ことが | Vision |
| 7 進行中 | おもろいことが**生まれる場所** | Vision |
| 8 問い | **誰を幸せにできるのかを問い続ける** | Value 1 |
| 9 年輪 | **過去から学ぶことを忘れない** | Value 2 |
| 10 縦組み | 日本語そのものを器にする | 全体 |

> **この作り方の利点：**どの案を選んでも、「なぜこのデザインなのか」をスポンサーにも次の代表にも一文で説明できる。
> 「かっこいいから」で選んだデザインは、代替わりの1年後に必ず崩される。**根拠のあるデザインだけが引き継がれる。**

### 10案すべてが守るもの（変更不可）

| # | 守るもの | 理由 |
|---|---|---|
| 0-1 | **Mission/Vision/Value は一字一句、原文どおり** | 大本資料 0-1。要約も「」囲みも禁止 |
| 0-2 | **私が書いた文は「仮コピー」と明示する** | 同上。団体の言葉と混ぜない |
| 0-3 | **不明な数字は空欄（`––`）** | 年間の企画数・部員数・作品の制作年は未確定 |
| 0-4 | **本文のコントラスト比 4.5 以上** | 大本資料 4-1 の実測表 |
| 0-5 | **写真が1枚も無くても成立する** | 使える写真が未確定 |
| 0-6 | **「北海道大学の公認団体ではない」旨を置く場所を確保** | 未来開拓倶楽部の傘下PJであり、非公認 |
| 0-7 | **題字はキルゴUのアウトラインSVG** | 2026-08-10 確定。ロゴが無いためこれが団体の顔 |
| 0-8 | **`prefers-reduced-motion` で動きを止める** | 大本資料 6章 |
| 0-9 | **`box-shadow` 禁止／角丸は1種類** | 原理3 |

### 使える素材（確定済み）

```
設立      2022年4月
メンバー  56名
部活      7つ  読書部・すこやか部・料理部・ふらっと部・
               言葉もてあそ部・研究室訪問部・ノンアルカクテル部

ロゴ      無し（＝題字が団体の顔）

```

⚠ **この素材の偏りが、案の向き不向きを決める。**
いま画面に置けるのは**部活7件とPJ7件、合計14件のテキストだけ**である。写真も作品もまだ無い。
**「たくさん並ぶと映える案」は、いま作ると成立しない。**これは10案を評価するうえで最も重要な現実である。

## 案1 ── 目録（CATALOGUE）

**翻訳した語句：**コンセプト「妄想の目録」／原理1「数が説得力である」

### 一言
すべてを**通し番号を振った目録**として並べる。サイトが1冊のカタログになる。

```
┌──────────────────────────────────────────────┐
│ 北大心理ゼミ                    HOKUDAI SHINRI│
├──────────────────────────────────────────────┤
│                                              │
│  大学生の溢れ出す妄想を形にする                │
│                                              │
├─────┬────────────────────┬─────────┬─────────┤
│ 001 │ 読書部              │ CLUB    │ ––      │
├─────┼────────────────────┼─────────┼─────────┤
│ 002 │ すこやか部          │ CLUB    │ ––      │
├─────┼────────────────────┼─────────┼─────────┤
│ 003 │ 料理部              │ CLUB    │ ––      │
├─────┼────────────────────┼─────────┼─────────┤
│ 004 │ ふらっと部          │ CLUB    │ ––      │
├─────┼────────────────────┼─────────┼─────────┤
│ 005 │ 言葉もてあそ部      │ CLUB    │ ––      │
├─────┼────────────────────┼─────────┼─────────┤
│ 008 │ 道東PJ              │ PROJECT │ 2026.09 │
└─────┴────────────────────┴─────────┴─────────┘
```

- **1pxの細い罫線**による表組み（v1の太い額縁とは正反対）。行の高さは詰める。
- 全項目に**通し番号**と**分類ラベル**（CLUB / PROJECT / EVENT / WORK）。
- 書体：番号とラベルは等幅、名前はゴシック。**明朝を使わない。**
- 色：墨と生成りのみ。朱は番号だけ。
- 動き：ホバーで行の地が墨に反転する、それだけ。

**強み**
- **項目が増えるほど強くなる。**表は行が増えて困らない唯一の構造。7部活→20部活でも破綻しない。
- **写真ゼロで最も寂しくない。**番号と罫線が絵になる。
- 空欄（`––`）が**表の中では自然**。「まだ埋めていない欄」に見え、隠しているように見えない。
- **実装が10案で最速。**表組み1つ。今月中の公開に最も現実的。

**弱み**
- **淡々としている。**「おもろい」は伝わらない。几帳面な団体に見える。
- v1と同じ「静」の系統で、**変化幅は10案で最小。**

**額縁適性（部活の独自ページを支えられるか）：◎ 最良**
表は中身が何色でも受け止める。7部活がそれぞれ違う作風でも、目録に並んでいれば散らからない。

**実装：◎ 最速（1〜2日）**

## 案2 ── 溢れる（OVERFLOW）

**翻訳した語句：**Mission「大学生の**溢れ出す**妄想を形にする」

### 一言
**文字と面が、画面から溢れて切れている。**収まりきっていないことを、そのまま見せる。

```
┌──────────────────────────────────────────────┐
│                                              │
│ 学生の溢れ出す妄想を形にす                    │← 左右が切れている
│                                              │
│  ┌───────────────────────────────────────────┤
│  │ 読書部  すこやか部  料理部  ふらっと部  言葉│← 右へ続いて切れる
│  └───────────────────────────────────────────┤
│                                              │
│████████████████████████████████████████████████←朱の面が断ち切れ
│                                              │
│ 北大で最も大量におもろいことが生まれる場所にな │← また切れる
│                                              │
└──────────────────────────────────────────────┘
```

- 見出しを**画面幅より大きく**組み、意図的に左右を断ち切る。
- 朱の面は必ず**画面の端まで**（フルブリード）。余白で囲わない。
- 部活の帯は横方向にはみ出して続く（スクロールで見える）。
- 色：生成り地＋朱の断ち切り面。
- 動き：スクロールで帯が逆方向にゆっくり流れる。

**強み**
- **Missionが説明抜きで伝わる。**「溢れ出す」が理屈でなく視覚。
- **写真ゼロでも画面が埋まる。**文字が絵になる。
- 10案で最も**現代的**（海外のエディトリアル系サイトの主流）。

**弱み**
- ⚠ **切れた文字は読めない。**Mission本文を切ると 0-1 ルール違反に近いことが起きる（原文が読めない状態になる）。
  → **切ってよいのは装飾として繰り返す文字だけ**とし、**MVVの原文は必ず全文が読める場所に別途置く**という制約が必要。この制約が、この案の設計を難しくする。
- スマホでは文字が大きすぎて**1画面に3文字**しか入らない事故が起きやすい。
- 横方向のはみ出しは、**ブラウザに横スクロールバーを出してしまう事故**が起きやすい（`overflow-x:hidden` の管理が必要）。

**額縁適性：△**
本サイト自体が強く主張するため、子ページとぶつかる。

**実装：○（3〜4日）**

## 案3 ── 整列（ALIGNMENT）

**翻訳した語句：**Mission「溢れ出す妄想を**形にする**」

### 一言
**散らかったものが、スクロールすると整列する。**Missionを画面で演じる。

```
  ［スクロール前］                ［スクロール後］
┌──────────────────┐          ┌──────────────────┐
│  ┌───┐    ┌────┐ │          │ ┌───┬───┬───┬───┐│
│ ┌┴──┐│  ┌─┴──┐ │ │   ──▶    │ │001│002│003│004││
│ │読書││  │料理│ │ │          │ ├───┼───┼───┼───┤│
│ └──┬┘│  └────┘ │ │          │ │005│006│007│008││
│   ┌─┴────┐ ┌────┤ │          │ └───┴───┴───┴───┘│
│   │ふらっと│ │道東│ │          │                  │
│   └───────┘ └────┘│          │  形になった      │
└──────────────────┘          └──────────────────┘
     妄想（散乱）                     形（整列）
```

- 部活・PJの紙片が、それぞれ違う角度（±1〜4°）で重なって散乱している。
- **スクロール量に応じて、角度が0°に戻り、格子に吸い込まれる。**
- 色：生成り地＋紙片ごとに淡い色。朱は見出し。
- 書体：紙片のラベルは普通のゴシック（手書き風フォントは安っぽくなるので使わない）。

**強み**
- **10案で最も「おもろい」。**Missionが説明でなく体験になる。
- **新歓で圧倒的に強い。**最初の3秒で「楽しそう」と思わせる。
- 目的1（自発的に投稿したくなる）に最も直結。

**弱み**
- **実装コストが10案で最大。**散乱座標・重なり順・スクロール連動・モバイル対応。
  **今月中の公開なら、トップ1枚に絞る必要がある。**
- スポンサー向けの真面目さが弱い（→ 団体紹介ページは整然と、で分離できる）。
- 回転した日本語は読みにくく、角度4°が上限。

**額縁適性：△**
本サイトが動きを持つため、静かな子ページと落差が出る。

**実装：✕ 最遅（1週間以上）**

## 案4 ── 図面（BLUEPRINT）

**翻訳した語句：**Mission「妄想を**形にする**」＝ 設計する

### 一言
**製図。**すべてに寸法線と引き出し線が付く。妄想を「設計対象」として扱う。

```
┌──────────────────────────────────────────────┐
│  ├─────────────── 56名 ───────────────┤       │
│  ┌──────────────────────────────────┐        │
│  │                                  │ ┐      │
│  │  大学生の溢れ出す妄想を形にする    │ │ 2022–│
│  │                                  │ ┘      │
│  └──────────────────────────────────┘        │
│         │                                    │
│         ├──── 部活 ────┬──── PJ ────┐        │
│         │              │            │        │
│      ┌──┴──┐       ┌───┴───┐    ┌───┴──┐    │
│      │ 07件 │       │ 進行1 │    │ 過去6│    │
│      └─────┘       └───────┘    └──────┘    │
│                                              │
│  ※ 寸法・数値は実測値。未確定は ―― と表記      │
└──────────────────────────────────────────────┘
```

- 細い墨線（0.5〜1px）だけで構成。**面を塗らない。**
- 寸法線・引き出し線・注記が、そのまま情報になる（`├── 56名 ──┤`）。
- 書体：注記はすべて等幅。
- 色：生成り地に墨線、**朱は寸法線と注記のみ。**

**強み**
- **「形にする」という団体の中核動詞を、最も正確に視覚化できる。**
- 数字を出す場所が構造的に用意されている（寸法線＝数値）。**スポンサー向けに強い。**
- **未確定を `――` と書くのが図面の作法として自然。**現状の情報不足と相性が良い。
- 線だけなので**極めて軽い。**

**弱み**
- **冷たく、工学的。**「おもろい」からは最も遠い。新歓には効かない。
- 図面らしい線は**手で1本ずつ引く**ことになり、見た目のわりに手間がかかる。
- 線が多いとスマホで潰れる。

**額縁適性：○**
線画は主張が弱いので子ページと喧嘩しない。ただし作風の落差は大きい。

**実装：△（4〜5日）**

## 案5 ── 物量（MASS）

**翻訳した語句：**Vision「北大で**最も大量に**おもろいことが生まれる」

### 一言
**画面を隙間なく埋め尽くす。**余白ゼロ。原理1の最大化。

```
┌──────────────────────────────────────────────┐
│読書部│████│料理部│すこやか│████│ふらっと│言葉も│
├─────┴────┴─────┴───────┴────┴──────┴──────┤
│████│研究室訪問│道東PJ│████│ノンアル│████│哲学│
├────┴─────────┴─────┴────┴───────┴────┴────┤
│ 大学生の溢れ出す妄想を形にする      │████│落書│
├────────────────────────────────────┴────┴───┤
│豆腐ゲーム│████│カードゲーム│詩タイピング│████│
└──────────────────────────────────────────────┘
      余白ゼロ。スクロールすると次の壁。
```

- タイルを敷き詰める。**余白を一切取らない。**
- タイルの色は墨／生成り／朱を市松に。
- 動き：ホバーでタイル1枚だけが反転。

**強み**
- Visionの「最も大量に」を**画面がそのまま証明する。**
- 一目で「たくさんある」が伝わる。

**弱み（⚠ 重大）**
- **いまのコンテンツ量では成立しない。**埋め尽くすには最低でも40〜50件必要だが、
  現在あるのは**部活7＋PJ7＝14件**。**スカスカになり、逆効果になる。**
- 原理3「引き算で品格をつくる」と**正面から衝突する。**大本資料を書き換える必要がある。
- 余白ゼロは**うるさく、安く見えるリスク**が高い。スポンサー向けに不利。

**額縁適性：✕**
本サイトが最も主張する案。子ページが埋もれる。

**実装：○（3日）**

> **正直な評価：この案は、コンテンツが十分に貯まった2〜3年後なら強力だが、いまは選ぶべきでない。**
> 「今は選べないが将来使える案」として記録しておく価値はある。

## 案6 ── 落差（PUNCHLINE）

**翻訳した語句：**Vision「**おもろい**ことが」

### 一言
**文字の大きさの落差だけで、抑揚をつくる。**写真も罫線も使わない。1画面1文。

```
 ［1画面目］            ［2画面目］           ［3画面目］
┌────────────┐      ┌────────────┐      ┌────────────┐
│            │      │            │      │            │
│            │      │  部活が    │      │            │
│  妄想      │      │            │      │  ぜんぶ    │
│            │      │  ７つ      │      │  学生が    │
│            │      │            │      │  言い出した│
│  ※極大    │      │  ※極大    │      │  ※小さく  │
└────────────┘      └────────────┘      └────────────┘
        大 → 小 → 大 の落差が「間」をつくる
```

- 1画面に1文だけ。**文字サイズの差を極端に**つける（120px と 15px を隣に置く）。
- 装飾は一切なし。生成りと墨のみ。朱は1ページに1語だけ。
- 動き：スクロールで次の文に切り替わる。フェードのみ。

**強み**
- **10案で最も「おもろい」を直接狙える。**間（ま）の設計は漫才と同じ。
- **写真も素材も一切不要。**文字だけで完成する。
- **実装が速い。**
- 額縁として優秀（文字だけなので子ページとぶつからない）。

**弱み（⚠ 重大）**
- **文を書く必要がある。**MVV以外の文は**すべて制作側が書くことになり、0-2 ルールにより「仮コピー」と明示**したうえで団体の承認が要る。
  **文の質がサイトの質を100%決める案**であり、**滑ると寒い。**
- **情報量がほぼゼロ。**スポンサーが知りたい実績・数字を置く場所が無い（下部に別途情報エリアが要る）。
- スクロール量が多く、せっかちな人は途中で離脱する。

**額縁適性：◎**

**実装：◎ 速い（2日）／ ただし文章作成の時間は別途**

## 案7 ── 進行中（IN PROGRESS）

**翻訳した語句：**Vision「おもろいことが**生まれる場所**になる」

### 一言
完成品ではなく、**いま動いているものを見せる。**すべてに状態表示が付く。

```
┌──────────────────────────────────────────────┐
│ 北大心理ゼミ                                  │
│ 大学生の溢れ出す妄想を形にする                 │
├──────────────────────────────────────────────┤
│                                              │
│ ● いま動いている                              │
│   ┌────────────────────────────────────────┐ │
│   │ 道東PJ            2026.09.04–06        │ │
│   │ ●───────────○────────────○  準備中     │ │
│   └────────────────────────────────────────┘ │
│                                              │
│ ○ かたちになった                              │
│   豆腐ゲームPJ  詩タイピングPJ  実験再現PJ …  │
│   （過去 6件）                                │
│                                              │
│ ◍ 続いている                                  │
│   読書部  すこやか部  料理部  ふらっと部 …    │
│   （7部活）                                   │
└──────────────────────────────────────────────┘
```

- すべての項目に**状態**（いま動いている／かたちになった／続いている）が付く。
- 状態が色になる：**進行中＝朱**、完了＝墨、継続＝薄灰。
- 状態バーで進み具合を示す。
- 動き：進行中の印だけがゆっくり明滅（reduced-motion で停止）。

**強み**
- **「生まれる場所」が構造そのもの。**静的な紹介でなく、動いている団体に見える。
- **過去PJ6件が資産になる。**捨てずに「かたちになった」として並べられる。Value「過去から学ぶことを忘れない」とも接続する。
- **更新が自然。**代替わりしても「状態を変えるだけ」で運用できる（引き継ぎやすさ＝大本資料の隠れ最重要制約）。
- スポンサーに「動いている団体」と伝わる。

**弱み**
- **未完成を見せることになる。**「やりかけが多い団体」に見えるリスク。
  → 対策：「かたちになった」6件を先に見せ、進行中を後に置く順序にする。
