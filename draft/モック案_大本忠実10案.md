### 今回の10案の作り方

大本資料には、**根拠つきで既に決まっている設計装置**が10以上あります（額装、二層構造、型A/B/C、圏点、囲み、新聞紙面ブロック、ピル3種、フォールバック、朱の乗算、非対称グリッド…）。
しかしモック v1 は、それらを**全部ちょっとずつ**使いました。結果が「堅い」という前回の評価です。

> **アーティスティックさは、装置を足すことではなく、1つを極端に振り切ることから出ます。**
> 10案は「**どの装置を主役にし、他を全部脇に回すか**」の10通りです。
> **どれを選んでも大本資料の範囲内**なので、資料を書き換える必要がありません。

## 案1 ── 額装の入れ子（FRAME IN FRAME）

**主役にする装置：6-1 額装** ／ ▸ 大本資料が「**費用対効果が最も高い一手**」と評価している装置

### 一言
額を**入れ子**にする。スクロールするほど紙が奥に重なり、「1冊の本をめくっている」感覚になる。

```
┌────────────────────────────────────┐ ← 墨の額（body）
│ ╭────────────────────────────────╮ │
│ │                                │ │ ← 生成りの紙（main）
│ │   北大心理ゼミ                  │ │
│ │   大学生の溢れ出す妄想を形にする  │ │
│ │                                │ │
│ │  ╭──────────────────────────╮  │ │ ← さらに内側の紙
│ │  │ 読書部  すこやか部  料理部 │  │ │
│ │  │ ふらっと部  言葉もてあそ部 │  │ │
│ │  ╰──────────────────────────╯  │ │
│ ╰────────────────────────────────╯ │
└────────────────────────────────────┘
```

### 実装の核
```css
body { background: var(--ink); padding: var(--frame); }
main { background: var(--paper); border-radius: var(--radius); }
.inner { background: var(--paper-card); border-radius: var(--radius);
         margin: var(--sp-8); }               /* 入れ子1段 */
/* スクロールで額の幅が育つ */
main { animation: deepen linear both; animation-timeline: view(); }
@keyframes deepen { to { margin-inline: var(--sp-8) } }
```

**強み**
- **CSS 3〜6行で完成する。**10案で最も安上がりに「作り込まれている」感が出る。
- 写真ゼロでも成立。素材に一切依存しない。
- コンセプト「妄想の目録＝1冊の本」を、装飾を足さずに表現できる。
- **額縁適性 ◎。**額の中に部活の独自ページを入れれば、作風が違っても「同じ本の中のページ」に見える。

**弱み**
- ⚠ **入れ子は2段が限界。**3段以上は内側が狭くなりすぎ、スマホで本文が読めなくなる。
- 額の分だけ**実質的な画面幅が減る**（`--frame: 8px` × 入れ子分）。情報量の多いページと相性が悪い。
- 単体では地味。**他の装置と併用しないと「枠があるだけ」で終わる。**

**実装：◎ 最速（1日）**

## 案2 ── 反転（INVERSION）

**主役にする装置：3章 二層構造の「地の反転」** ／ ▸ 大本資料が「⚠ 層の切り替えは**地の色の反転だけ**で表現する。別の装飾を足さない」と定めている

### 一言
**地の色が、生成りと墨で入れ替わり続ける。**それ以外の演出を一切しない。

```
 ［妄想の層］          ［静謐の層］         ［妄想の層］
┌───────────┐      ┏━━━━━━━━━━━┓      ┌───────────┐
│生成り #F4F1EA│      ┃ 墨 #0E0E0E ┃      │生成り      │
│           │      ┃            ┃      │           │
│ ■北大心理  │ ──▶ ┃ □北大心理   ┃ ──▶ │ ■北大心理  │
│   ゼミ     │      ┃   ゼミ      ┃      │   ゼミ     │
│           │      ┃            ┃      │           │
│ 妄想       │      ┃ 形にする    ┃      │ おもろい   │
└───────────┘      ┗━━━━━━━━━━━┛      └───────────┘
   題字は currentColor なので、地に応じて自動で反転する
```

### 実装の核
```css
section { background: var(--paper); color: var(--ink);
          transition: background .4s, color .4s; }
section.invert { background: var(--ink); color: var(--paper); }
/* 題字・罫線・ピルがすべて currentColor なので、これ1行で全部が反転する */
.logomark path { fill: currentColor; }
.pill--outline { border-color: currentColor; color: currentColor; }
```

**強み**
- **題字の作り（`fill:currentColor`）が、ここで最大限に活きる。**キルゴUの超極太が墨地で白抜きになる瞬間が、このサイトで最も強い絵になります。
- **大本資料の決定を、そのまま最大化しているだけ。**新しい判断が一切要らない。
- 写真ゼロで成立。素材に依存しない。
- 二層構造（妄想／静謐）という団体の性格が、見た目でそのまま伝わる。
- **実装が速く、軽い。**

**弱み**
- ⚠ **色を2つ用意する必要が全要素に生じる。**朱は `--shu-on-light`（4.87）と `--shu-on-dark`（6.88）の使い分けが必須で、**間違えるとコントラスト不足になる**。CSS変数をセクション単位で切り替える設計にしないと事故ります。
- 反転の回数が多いと**目が疲れる。**3〜4回が上限。
- 単体では「色が変わるだけ」。**構造（前回の10案）と組み合わせて初めて成立する。**

**額縁適性：○**（子ページは生成り固定にすればよい）
**実装：◎ 速い（1〜2日）**

## 案3 ── 柱（PILLAR）

**主役にする装置：6-3 型A の左ラベル＋5-3 縦組み** ／ ▸「左のラベルだけ書体・向きを変えて対立させるだけで**雑誌の柱**になる。日本語では縦組みにするとさらに効く」

### 一言
**画面の左端に、縦組みの柱が1本立ち続ける。**右側だけが流れていく。

```
┌────┬─────────────────────────────────┐
│    │ 読書部                           │
│ 部 │ 2026年4月設立                     │
│ 活 │                                  │
│    │ すこやか部                        │
│ ●  │ 2026年4月設立                     │
│    │                                  │
│ 縦 │ 料理部                            │
│ 組 │ 2026年4月設立                     │
│ み │                                  │
│    │ ふらっと部                        │
│sticky│ 2026年4月設立                    │
└────┴─────────────────────────────────┘
  2/12          10/12          ← 6-2 の非対称グリッド
```

### 実装の核
```css
.pillar { writing-mode: vertical-rl; position: sticky; top: 0;
          height: 100svh; font-size: 32px; letter-spacing: .3em;
          border-right: 1px solid currentColor; }
```

**強み**
- **縦組みを「1本の柱」に限定するので、案10（全面縦組み）のスマホ問題が起きない。**縦組みの美味しいところだけ取れる。
- **大本資料 5-3 が「セクションの柱を1本だけ」と明記している使い方そのもの。**逸脱ゼロ。
- 部活7件・PJ7件という**いまの素材量にちょうど合う。**多すぎず少なすぎない。
- 日本語サイトらしい品格が最も安く出る。

**弱み**
- ⚠ **スマホでは柱を置く横幅が無い。**上部の横帯に切り替える分岐が必要（＝実装が2通りになる）。
- 柱が固定されるため、**1セクションが長いと柱の文字がずっと同じで飽きる。**
- 右側のレイアウトが自由すぎると、柱だけ浮く。

**額縁適性：○**
**実装：△（3〜4日。スマホ分岐が主因）**

## 案4 ── めくり（STICKY FULLBLEED）

**主役にする装置：6-3 型B のフルブリード＋sticky** ／ ▸「`position:sticky; height:100svh` で行を重ねると、1件ずつ**めくる**体験になる」

### 一言
**1画面＝1件。**スクロールすると次の面が上から覆いかぶさる。

```
 ［1件目］              ［スクロール中］        ［2件目］
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│道東PJ         │    │道東PJ         │    │読書部         │
│進行中 2026.09 │    │━━━━━━━━━━━━━━│    │2026年4月〜    │
│              │    │読書部         │    │              │
│  （全面）     │    │  ↓覆いかぶさる │    │  （全面）     │
│              │    │              │    │              │
└──────────────┘    └──────────────┘    └──────────────┘
```

- キャプションは大本資料どおり **`名前 / 所属・人 / 年` の3行固定**。
- 写真が無い件は 6-4 のフォールバック（`--paper-card` 地＋名前だけ）。

### 実装の核
```css
.sheet { position: sticky; top: 0; height: 100svh;
         display: grid; align-content: end; }
.sheet:nth-child(odd)  { background: var(--paper); }
.sheet:nth-child(even) { background: var(--ink); color: var(--paper); }
```

**強み**
- **1件あたりの印象が10案で最も強い。**14件しか無いことが、逆に「1件ずつ丁寧に見せている」に見える。
- 案2（反転）と自然に合体する（面が交互に墨と生成り）。
- **キャプション3行がそのまま投稿データのスキーマ**（9-1）なので、将来の投稿機能と一直線につながる。

**弱み（⚠ 重大）**
- ⚠ **写真が無いと、全画面が `--paper-card` の無地になる。**14画面連続で無地の面が続くのは、いま作ると**かなり寂しい**。この案は**写真が揃ってから**が本番です。
- スクロール量が非常に多い。**せっかちな人（＝スポンサー）は途中で離脱する。**
- 一覧性がゼロ。「どんな部活があるか」を俯瞰できない。

**額縁適性：△**
**実装：○（2〜3日）／ ただし写真が揃うまで本領を発揮しない**

## 案5 ── ピルの海（PILL FIELD）

**主役にする装置：6-3 型C 散らしたピル＋7-3 ピル3種** ／ ▸「原理1『数が説得力である』を実装する**主役**」

### 一言
**部活・PJ・イベントのピルが、画面いっぱいに散る。**塗り／反転／線の3種を混ぜ、Y座標をばらす。

```
┌──────────────────────────────────────────────┐
│                                              │
│    (読書部)        ▓道東PJ▓      ( 料理部 )   │
│                                              │
│  ▓すこやか部▓   (言葉もてあそ部)    ▓進行中▓  │
│                                              │
│      大学生の溢れ出す妄想を形にする            │
│                                              │
│ (ふらっと部)   ▓研究室訪問部▓   (豆腐ゲームPJ) │
│                                              │
│   ▓ノンアルカクテル部▓   (詩タイピングPJ)      │
│                                              │
│  ▓＝朱地×墨文字(4.78)  ()＝線のみ  ■＝墨地×朱 │
└──────────────────────────────────────────────┘
```

### 実装の核
```css
.pill--fill    { background: var(--shu); color: var(--ink); }   /* 4.78 AA */
.pill--outline { border:1.5px solid var(--ink); color: var(--ink); }
.pill--invert  { background: var(--ink); color: var(--shu-on-dark); } /* 6.88 AA */
.field li:nth-child(3n)   { margin-top: var(--sp-6); }  /* Y座標をばらす */
```

**強み**
- **朱が10案で最も映える。**アクセント色を決めた意味が、ここで初めて回収される。
- **14件でちょうど画面が埋まる。**（案5「物量」＝タイル敷き詰めは40件必要でしたが、ピルなら14件で成立します）
- 項目が増えるほど賑やかになる。Visionが増えるほど強くなる。
- 実装が単純で、**スマホでも自然に折り返す。**

**弱み**
- ⚠ **朱の使いすぎに注意。**大本資料 4-1 は「朱を生成り地の本文サイズに使わない」と定めており、ピルは14px なので `--shu` 地に**墨文字**でなければなりません。反転ピルの文字は `--shu-on-dark`。**ここを間違えると全滅します。**
- ばらけ方が「ランダム」だと汚くなる。**`nth-child` で規則的にずらす**のが正解（真のランダムは使わない）。
- 単体だと**タグ一覧に見える。**上下に強い見出しが要る。

**額縁適性：○**
**実装：◎ 速い（1〜2日）**

## 案6 ── 紙面（NEWSPAPER）

**主役にする装置：7-6 新聞紙面ブロック** ／ ▸「**団体紹介を新聞にすると、退屈な『会社概要ページ』ではなく紙面になる。**スポンサー向けの信頼感とアーティスティックさが同時に成立する数少ない解」

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ┃ MISSION       ┃ 部活 07        ┃ 数字
 ┃ 大学生の溢れ出す┃ 読書部         ┃ 設立   2022.04
 ┃ 妄想を形にする  ┃ すこやか部      ┃ 会員   56名
 ┃               ┃ 料理部         ┃ 部活   7
 ┃ VISION        ┃ ふらっと部      ┃ PJ    1 (＋過去6)

 ┃ おもろいことが  ┃ 研究室訪問部    ┃

 ┃ VALUE         ┃ 道東PJ         ┃
```

- 縦罫（`border-left: 1px`）で段を分け、段ごとに文字サイズを変える。

**強み**

- ⚠ **スマホで多段組は不可能。**1列に落とすと、ただの縦長リストになり紙面感が消える。**スマホ用に別の見せ方を作る必要がある**（10案で最も分岐が重い）。
- 新歓には効かない。**1年生は新聞を読まない。**
- 文字が小さくなりがちで、**本文17px を守ると段が入らない**というジレンマがある。

**額縁適性：△**（紙面は主張が強い）
**実装：△（4〜5日。スマホ分岐が主因）**

## 案7 ── 圏点（KENTEN）

**主役にする装置：5-3 圏点** ／ ▸「**日本語だけが持つ強調**であり、ウェブではほとんど使われていない。調査した事例70件のいずれも使っていなかった。**1語だけに朱で打つと、他サイトと明確に差がつく**」

### 一言
**装飾を全部捨て、圏点だけを残す。**極端に静かで、核心の1語にだけ朱の点が打たれる。

```
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│                  ・・                         │
│      大学生の溢れ出す妄想を形にする             │
│                                              │
│                                              │
│                                              │
│                      ・・・・                  │
│      北大で最も大量におもろいことが生まれる場所になる│
│                                              │
│                                              │
│                    ・・・                     │
│      誰を幸せにできるのかを問い続ける           │
│                                              │
│         ・＝朱の圏点（filled sesame）          │
└──────────────────────────────────────────────┘
```

### 実装の核
```css
.kenten { text-emphasis: filled sesame;
          text-emphasis-color: var(--shu-on-light); }  /* 4.87 AA */
.has-kenten { line-height: 1.55; }   /* ⚠ 圏点は行の上に出る。1.2のままだと上の行と重なる */
```

**強み**
- **調査した事例70件が誰も使っていない。**差別化として10案で最も確実。
- **MVVの原文を一字も変えずに、核心を示せる。**（0-1のルールと完全に両立する数少ない手法）

## 案9 ── 朱の乗算（MULTIPLY）

**主役にする装置：6-5 写真の品質差を吸収する処理** ／ ▸「学生がスマホで撮った写真は明るさも色も構図もバラバラ。**サイト側で一律に処理すれば、学生に画像編集を要求せずに統一感が出る**」

### 一言
**すべての写真を白黒にし、朱を乗算で重ねる。**ホバーした1枚だけが本来の色に戻る。

```
 ［通常］                    ［ホバー］
┌──────┐┌──────┐┌──────┐   ┌──────┐┌──────┐┌──────┐
│▨▨▨▨▨▨││▨▨▨▨▨▨││▨▨▨▨▨▨│   │▨▨▨▨▨▨││ 原色  ││▨▨▨▨▨▨│
│朱に沈む││朱に沈む││朱に沈む│   │朱に沈む││ に戻る││朱に沈む│
└──────┘└──────┘└──────┘   └──────┘└──────┘└──────┘
   grayscale(1) + 朱 multiply .28    hover で filter:none
```

### 実装の核
```css
.thumb { filter: grayscale(1) contrast(1.12);
         transition: filter .4s cubic-bezier(.16,1,.3,1); }
.thumb::after { content:""; position:absolute; inset:0;
  background: var(--shu); mix-blend-mode: multiply; opacity:.28; }
.card:hover .thumb { filter: none; }
.card:hover .thumb::after { opacity: 0; }
```

**強み**
- **バラバラな写真が一瞬で統一される。**学生に「いい写真を撮って」「加工して」と頼まなくて済む。これは**運用上とても大きい。**
- ホバーで色が戻る瞬間が気持ちよく、**触りたくなるサイトになる。**目的1（投稿したくなる）に効く。
- 実装は6行。

**弱み（⚠ 重大）**
- ⚠ **写真が無いといま作れません。**10案で唯一、素材が完全に前提条件になっている案です。
- ⚠ 大本資料 6-5 に「**作品集ページには適用しない。作品そのものの色を変えてはならない**」とあります。つまり**この案は作品集では使えず、サイト全体の統一言語にはなれない。**
- スマホにはホバーが無い。タップで色が戻る設計が別途必要。

**額縁適性：○**
**実装：◎ 速い（1日）／ ただし写真が揃うまで着手不可**

## 12. 私の推奨

### 視覚言語

```
地の言語   案2（反転）＋ 案1（額装）      … 全ページの下地
主役       案6（紙面）を団体紹介に
           ＋ トップは案8（欠落）で今すぐ公開できる形に
仕上げ     案7（圏点）を MVV に1語だけ
           ＋ 案5（ピル）を部活・PJの一覧に
```

### 前回の10案との合体

```
情報の構造（前回 案7「進行中」）
   × 視覚言語（今回 案2「反転」＋案1「額装」）
   × 仕上げ（今回 案7「圏点」・案5「ピル」）
```

**この組み合わせを選ぶ理由を3つ挙げます。**

1. **全部いま作れます。**写真も追加取材も要りません。案4（めくり）と案9（乗算）だけが写真を必要としますが、**この2つは後から足せます**（写真が集まったら、案8の面を案9の処理に差し替えるだけ）。
2. **大本資料を1行も書き換えずに済みます。**10案すべてが資料内の装置なので、根拠を後から説明できます。次の代表に引き継ぐときも「資料の◯章です」で説明が終わります。
3. **案2（反転）が、題字の作り方を回収します。**キルゴUをアウトラインSVGにして `fill:currentColor` を指定したのは、まさにこの瞬間のためでした。**墨地で超極太の題字が白抜きになる**のが、このサイトで最も強い一枚になります。

### 迷った場合の、もう一つの選択肢

**アーティスティックさを最優先するなら、案3（柱）です。**
縦組みの柱が1本立っているだけで、他のどの学生団体サイトとも違う見た目になります。ただし**スマホ用の分岐が必要**で、実装が3〜4日に伸びます。今月中の公開なら、案3は**第2弾**に回すのが安全です。
