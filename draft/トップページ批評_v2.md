# トップページ モック v2 の批評と改善案

作成日：2026-08-10
対象：`draft/mock_top_v2.html`（PJ掲載・部活の終了2件を追加した状態）
評価基準：`draft/デザイン大本資料_v1.md` ／ `reference/design-research/` 01〜08

## 0. 実測データ（批評の根拠）

批評は印象ではなく、ブラウザで計測した数値に基づきます。

| 項目 | 実測値 | 評価 |
|---|---|---|
| ページ全長 | **7,383px（約11.7画面）** | ⚠ 長い |
| **空の写真枠が縦方向に占める割合** | **55.4%（4,091px）** | ❌ **最大の問題** |
| 空の写真枠の数 | **20個** | ❌ |
| ページ全体の文字数 | **1,137字** | ⚠ 薄い |
| 1,000pxあたりの文字数 | **154字** | ⚠ かなり薄い |
| 型Aの左ラベル列の幅 | 157〜171px × 高さ最大1,508px | ⚠ ほぼ空白 |
| 札の数 | 20個（部活9・PJ10・イベント1） | ○ |

> **1行でまとめると：ページの半分以上が、中身のない桃色の四角です。**

---

## 1. 良い点（先に、短く）

批評の前に、機能している部分を挙げます。**これらは変えないほうがよいものです。**

| # | 良い点 | なぜ良いか |
|---|---|---|
| 1 | **題字（キルゴU）** | 圧倒的に強い。ロゴが無い団体の顔として完全に成立している。ここは触らない |
| 2 | **圏点（「妄想」の朱のゴマ点）** | 事例70件の誰も使っていない手法。**原文を1字も変えずに核心を示せている** |
| 3 | **数字の誠実さ** | `––` を残していること自体が信用になる。埋めたくなっても埋めないこと |
| 4 | **整列（散乱→格子）** | Missionを説明せずに演じている。JSゼロで動く。これは正解 |
| 5 | **終了を消さない設計** | Value「過去から学ぶことを忘れない」がデータ構造として実装されている |

## 2. 問題点（重大な順）

### 🔴 問題1：ページの55%が「空の桃色の四角」である

**これが他のすべての問題より重大です。**

朱の乗算（大本資料 6-5）は、**写真があって初めて機能する装置**です。
写真が無い状態では、`--paper` の地に朱を28%乗算した**均一な桃色の面**が20個並ぶだけになります。

```
現在：  ┌────────┐ ┌────────┐ ┌────────┐
        │        │ │        │ │        │   ← 全部おなじ桃色
        │  (桃)  │ │  (桃)  │ │  (桃)  │      情報量ゼロ
        └────────┘ └────────┘ └────────┘
         読書部     すこやか部   料理部
```

**⚠ しかも、これは大本資料 6-4 の違反です。**

> 6-4：画像が無いときのフォールバック（⚠ 必須）
> `cover` が空のとき `--paper-card` 地＋名前だけのブロックに切り替える

**私は 6-4 を実装せず、空の枠にそのまま乗算をかけていました。** 設計どおりに作っていません。

さらに悪いことに、**「終了」の表現が壊れます。** いま終了カードは乗算を .28→.14 に弱めていますが、
写真が無いので**桃色が薄いだけの四角**になり、「終了」ではなく「読み込み失敗」に見えます。

---

### 🔴 問題2：スポンサーが最初の1画面で得る情報がゼロ

大本資料の決定事項5は「**最優先読者＝スポンサー・外部の大人。トップを開いて最初の3秒**」です。
`06資料` も「**スポンサーは回遊せず、1回見て判断する**」と書いています。

**現在の第1画面にあるのは、ナビ・題字・Missionの一文だけです。**

- この団体が何をしているか → 分からない
- どれくらいの規模か → 分からない
- いま動いているか → 分からない

**設立2022年・56名・部活7・PJ5** という、最も効く情報は**3画面目**にあります。
スポンサーはそこまでスクロールしません。

---

### 🟡 問題3：11.7画面あるのに、文字が1,137字しかない

1,000pxあたり**154字**。これは「余白が広い」ではなく「**中身が無い**」水準です。

原因は2つ。

1. `section` の上下余白が `--sp-24`（192px）× 7セクション ＝ 上下で約2,700px
2. **紹介文が部活・PJに1本ずつしかない**（各部活の紹介文が未提出）

余白は「引き算の品格」（原理3）のつもりでしたが、**引き算すべき中身がまだ無い**段階では、
ただの空白になります。**余白は中身があって初めて効きます。**

---

### 🟡 問題4：型Aの左ラベル列が、巨大な空白を作っている

`.two` は `2fr : 10fr`。左列は幅157〜171pxで、**高さ1,508pxのうち文字があるのは上端の数十pxだけ**です。

```
┌──────┬────────────────────────────┐
│  P   │ （カードが1,500px続く）      │
│  J   │                            │
│      │                            │
│ ← ここが1,400px以上、完全な空白      │
│      │                            │
└──────┴────────────────────────────┘
```

大本資料 6-3 の型Aは**「雑誌の柱」**として引用しましたが、
`blanca_02_experience_2col.jpg` の原典では**項目が短いリスト**に対して使われています。
**1,500pxのカードグリッドに対して使う型ではありません。**

---

### 🟡 問題5：「終了」が多く見え、勢いが削がれている

現在の表示：**部活 9件中2件が終了／PJ 10件中5件が終了**。
札の一覧では、20個中7個（35%）が薄い灰色です。

これは**事実であり、隠すべきではありません。**
しかしVision「**北大で最も大量におもろいことが生まれる場所になる**」を掲げるトップページで、
**3分の1が灰色**なのは、伝わり方として損をしています。

> ⚠ **誤解しないでください。数字を偽れという話ではありません。**
> 「終了5件」は、**見せ方次第で「5つやり切った」という強みになります。**
> いまは「5つ止まった」に見えている、という配置の問題です。

---

### 🟡 問題6：額装の3層が、ほぼ見えていない

`--paper`（#F4F1EA）と `--paper-card`（#E8E5DE）のコントラスト比は **1.115**。
大本資料 4-1 が自ら「**差は1.115しかない**」と警告している値です。

結果、「墨の額 → 生成りの紙 → 紙灰の面」の3層は、**実際には1.5層くらいにしか見えません。**
一方で `margin-inline: var(--sp-6)` の分だけ**横幅は確実に失っています**。
**払ったコストに対して、得ているものが小さい。**

---

### 🟢 問題7：道東合宿（9/4-6）の扱いが弱い

**サイト上で唯一、期限のある情報**です。公開が8月中なら、告知として最大の価値があります。
しかし現在は、20個の札のうちの1つ＋ページ中盤のセクション、という扱いです。

---

### 🟢 問題8：ナビの先頭「作品集」が空のページに繋がる

5タブの先頭が、公開時点で中身ゼロです。**最初にクリックされる導線が空**なのは避けたい。

## 3. 改善案

**優先度順です。上の3つだけでも、印象は大きく変わります。**

### 改善1 🔴：写真が無い枠を、6-4のフォールバックに戻す

**大本資料どおりに実装し直します。**

```
改善後： ┌────────┐ ┌────────┐ ┌────────┐
         │        │ │        │ │        │  ← --paper-card の無彩色の地
         │ 読書部  │ │すこやか部│ │ 料理部  │  ← 名前を枠の中に大きく
         │        │ │        │ │        │
         └────────┘ └────────┘ └────────┘
          活動中      活動中      活動中
```

```css
/* 写真が無い枠：朱をかけない。名前を面の中に置く */
.thumb:empty{
  background:var(--paper-card);
  display:grid; place-items:center;
}
.thumb:empty::before{ content:attr(data-name); font-weight:700; font-size:20px; }
.thumb:empty::after{ opacity:0; }        /* 乗算レイヤーを無効化 */
```

- **朱の乗算のCSSは残します。**写真が1枚入った瞬間、その枠だけが乗算に切り替わります。
- **写真が集まっていく過程が、そのまま画面に出ます。**これは弱点ではなく物語になります。
- ⚠ 大本資料 6-5 の「終了は乗算を弱める」も、**写真がある枠だけに適用**します。
  写真の無い終了枠は**枠線を破線にする**など、色に頼らない区別に変えます。

### 改善2 🔴：ヒーローに「数字」を上げる

題字とMissionの直下に、1行だけ置きます。**スクロール不要にします。**

```
        北大心理ゼミ（題字）

        大学生の溢れ出す妄想を形にする
                    ・・

   ────────────────────────────────────────
    2022年設立 ／ 56名 ／ 部活 7 ／ PJ 5 ／ 進行中
   ────────────────────────────────────────
```

- **数字は既に確定しているものだけ。**`––` はここに出しません（第1画面に空欄を出さない）。
- 詳しい数字欄は現在の位置に残します。ヒーローのものは**要約**です。
- これだけで、**スポンサーが3秒で「4年続く56人の団体」と分かります。**

### 改善3 🔴：道東合宿を、ヒーロー直下の帯にする

```
  ┌──────────────────────────────────────────────┐
  │ 近日開催   道東合宿   2026.09.04–06      詳細 →│  ← 朱の帯
  └──────────────────────────────────────────────┘
```

- 朱の面＋墨の文字（4.78 AA）。**画面で朱を使う場所をここ1箇所に集約します。**
- イベントが終わったら帯ごと消す運用にします（次のイベントが決まるまで非表示）。
- ⚠ これにより、20個の札の中の朱チップは**通常の札に戻します**。朱が2箇所あると効果が半減します。

### 改善4 🟡：札を3群に分け、見出しを付ける

いま20個が1つのグリッドに混在しています。**部活／PJ／終了したもの**の3群に分けます。

```
   部活 7                          ← 見出し
   (読書部)(すこやか部)(料理部)…

   PJ 5                            ← 見出し
   (哲学カフェPJ)(落書き本PJ)…

   これまでにやったこと 7           ← 終了分をここへまとめる
   (ラジオ部)(心理シェア部)(トーク力向上PJ)…
```

**これが問題5（終了が多く見える）の解決でもあります。**
散らして混ぜると「3分の1が止まっている」に見えますが、
**「これまでにやったこと 7件」とまとめると、積み重ねに見えます。**事実は1文字も変えていません。

### 改善5 🟡：型Aの左ラベルを、カードグリッドには使わない

- **カードグリッドのセクション（部活・PJ）**：左ラベルをやめ、**上に横書きの見出し**を置いて全幅を使う
- **左の縦組みラベルは、短いリストのセクションだけに残す**（原典 `blanca_02` の使い方に戻す）

これで問題4の空白が消え、カードが1行3列→4列になり、**ページ全長が約1,500px縮みます。**

### 改善6 🟡：セクション余白を `--sp-24`(192px) → `--sp-16`(128px) に

中身が増えたら戻します。**いまは空白が多すぎます。**
改善5と合わせて、ページ全長は **7,383px → 約5,200px（8.2画面）** になる見込みです。

### 改善7 🟢：額装を2層にする

`.sheet`（第3層）を使うのは**ヒーローとValueだけ**に絞ります。
中間のセクションは `--paper` のまま全幅を使います。
→ 3層が「たまに効く」ようになり、横幅も戻ります。

### 改善8 🟢：非公認の一文を、フッターだけでなく団体紹介の冒頭にも置く

スポンサーが最初に確認したい情報です。最下部だけだと見落とされます。

### 改善9 🟢：ナビの「作品集」を、公開時は最後尾に移すか「準備中」を明示

空のページが先頭にあるのは避けます。作品が集まったら先頭に戻します。

## 4. やらないほうがよいこと

改善案を考える過程で検討し、**採らないと判断したもの**です。

| 案 | 却下の理由 |
|---|---|
| 仮の写真（フリー素材）を入れる | **団体の実態を偽ることになります。**フリー素材の楽しげな学生の写真は、この団体の写真ではありません |
| 終了した部活・PJを消す | Value「過去から学ぶことを忘れない」に反します。作品のリンク切れも起きます |
| 数字の空欄を推測で埋める | CLAUDE.md 3-4。**`––` は弱さではなく誠実さです** |
| 朱をもっと使って賑やかにする | 4-1の制約に触れます。朱は**面にだけ**使い、量を増やすと効果が落ちます |
| アニメーションを増やす | 8-4「1画面に同時に動く要素は3つまで」。整列で既に上限です |

## 6. 総評

**構造と根拠は良い。しかし、いま画面に出ているものは、まだ「設計図」であって「サイト」ではありません。**

題字・圏点・整列・終了を消さない設計── これらは**他の学生団体サイトには存在しない水準**です。
問題は、それらが**20個の空の桃色の四角に埋もれている**ことです。

**最大の原因は、私が大本資料 6-4（フォールバック必須）を実装しなかったことです。**
資料には「運用上、決定的に重要」と自分で書いておきながら、実装で飛ばしました。
**改善1は、新しいアイデアではなく、決めたとおりに作り直すことです。**

写真は無くていい設計にしてあります。**無いなりの見え方を、ちゃんと作っていなかっただけです。**
