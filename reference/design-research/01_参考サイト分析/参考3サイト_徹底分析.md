調査日：2026-08-09 ／ 調査方法：実ブラウザ（Chrome 1440×900）で表示し、`getComputedStyle` によりフォント・色・サイズを実測。数値は実測値、推測部分は「推測」と明記。

## A. blancavillalobos.com（BLNK℠）

**種別**：個人ブランドデザイナーのポートフォリオ（1ページ・スクロール型）
**技術**：Webflow（画像CDN `cdn.prod.website-files.com` から判別）

### 実測データ

| 項目 | 実測値 |
|---|---|
| 本文フォント | `Degular Text`（有料・OH no Type Co.） |
| 見出しフォント | `Switzer Variable`（**無料**・Fontshare） |
| アクセント書体 | `Playfair Display Variable`（**無料**・Google Fonts）※イタリックのラベルに使用 |
| 本文サイズ | 14px |
| 主要色 | `#1D1D1D`（84回・実質の黒）／`#000000`／`#FFFFFF`／`#999999`（副次テキスト）／`#2B2B2B` |
| ページ全長 | 7,831px |

### 盗むべき構造パターン

**① ラベル／本文の2カラム（`blanca_02_experience_2col.jpg`）**
```
左20%           右80%
• Experience    Lead Brand Designer @Revolut      ← 18px前後・#1D1D1D
（伊体セリフ）   December 2022 — Present           ← 同サイズ・#999999
（12px・小）
                Global Brand Digital Designer
                @Zalando
                March 2020 — December 2022
```
- 左のラベルだけ **イタリックのセリフ体＋行頭に「•」** で、本文のグロテスクと書体的に対立させている。これだけで「雑誌の柱」感が出る。
- **注釈：これは本サイトの「部活紹介」「PJ紹介」の一覧にそのまま転用できる。** 左＝カテゴリ（例：*• 部活*）、右＝名称＋期間／人数。実装コストはCSS Gridのみでほぼゼロ。

**② フルブリード作品行＋オーバーレイ・キャプション（`blanca_03_works_fullbleed.jpg`）**
```
┌──────────────────────────────────────────────┐
│ REVOLUT                          View project│ ← 画像の上に白文字で直置き
│ Brand & visual design, creative direction    │
│ 2023                                          │
│                                               │
│           （動画／画像が画面幅いっぱい）        │
└──────────────────────────────────────────────┘
```
- キャプションは **3行固定フォーマット**：`タイトル` / `役割・分類` / `年`。右端に `View project`。
- カード（枠・影・角丸）を一切使わず、**画像そのものをカードにしている**。余白と情報の密度で「高級感」を作る典型手法。
- **注釈：本サイトの「作品集」トップに最適。** 3行フォーマットは `作品名 / 制作者・所属部活 / 年` に置換すれば、投稿データのスキーマがそのまま決まる。

### 弱点（真似しないほうがよい点）
- 見出しが `<h1>/<h2>` タグとして存在せず（実測で `headings: []`）、SEO・スクリーンリーダー的には劣る。**スポンサーに検索で見つけてもらいたい本件では、必ず正しい見出しタグを使うこと。**
- 本文14pxは日本語には小さすぎる（日本語は同ptで小さく見える）。**本件では16px以上を推奨。**

## B. nexusmag.eu（NEXUSMAG）

**種別**：AI・クリエイティブ・アート・マーケティングのオンラインマガジン（チェコ語）
**技術**：**Framer**（フォント名の `"Rubik Placeholder"` 等はFramer特有のフォールバック指定）

### 実測データ

| 項目 | 実測値 |
|---|---|
| 使用フォント | `Rubik` / `Rubik Variable` / `DM Sans` / `Inter`（**すべてGoogle Fonts・無料**） |
| 主要色 | `#000000`（1344回・圧倒的主役）／`#FFFFFF`／**`#D7FF37`（ライムイエロー・アクセント）**／`#0C0C0D`／`#E6E6E6`／`#737373`／`#F5F5F5` |
| H1 | 45px / weight 500 / **line-height 45px（＝1.0）** |
| H2 | 31px / weight 500 / line-height 31px（＝1.0）/ **letter-spacing −1.24px（＝−0.04em）** |
| H3 | 20px / weight 500 / line-height 32px（＝1.6）|
| 角丸 | `30px`（72回・主役）／`20px`（29回）／`50px`（ピル） |
| ページ全長 | 5,869px |

### 盗むべき構造パターン

**① 「パスパルトゥー（額装）」レイアウト（`nexusmag_01_hero_frame.jpg`）**
- ページ全体が **黒い太枠の内側**に置かれ、四隅が大きく角丸。ブラウザ窓の中にもう一つ「紙面」があるように見える。
- ヒーローには **ライムの斜線が1本、画面を斜めに横切る**だけ。装飾はそれだけ。
- ロゴタイプの下に **ライムの手描き風ジグザグ下線**。
- **注釈：この「額装」は本件のコンセプトと非常に相性がよい。** 「大学生の妄想を1冊の雑誌として綴じる」という比喩が、構造そのもので表現できる。実装は `body { padding: 8px; background:#000 }` ＋ `main { border-radius: 30px; background:#fff }` 程度で済む＝**低コストで最も効果が高い一手**。

**② カテゴリのピル群を「散らして」置く（`nexusmag_02_tags_filter.jpg`）**
```
        ( COPYWRITING )              ( UMĚNÍ )
( MARKETING )   ( KREATIVITA )   ( AI )  ( TECHNOLOGIE )
```
- 塗り（ライム地×黒文字）と反転（黒地×ライム文字）を**交互に**混ぜ、Y座標をわざとバラす。
- **注釈：本サイトの「部活」一覧（読書部・すこやか部・ふらっと部・料理部…）に直結。** 部活が増えるほど画面が賑やかになる＝**「北大で最も大量におもろいことが生まれる場所」というVisionが、UI自体で証明される**。これは本件で最も推したいアイデア。

**③ フィルタバー（`nexusmag_02_tags_filter.jpg` 下部）**
```
Vyber si rubriku │ Vyhledej, co potřebuješ │ Vyber si autora │ Inspiruj se
[ 全記事      ▾] │ [🔍 記事を検索      ] │ [ 全著者    ▾] │ [ おすすめ ○]
```
- グレー地（#F5F5F5）の角丸バーに4つの操作を横一列。ラベルが**命令形の話し言葉**（「選べ」「探せ」「インスパイアされろ」）。
- **注釈：作品集の絞り込みに転用。** ラベルを「部活で選ぶ／PJで選ぶ／人で探す」にすれば、5タブ構成の横断導線になる。

**④ 記事グリッド（`nexusmag_03_article_grid.jpg`）**
- 3カラム、カードは **薄グレー地（#F5F5F5）＋角丸20px、枠線なし、影なし**。
- サムネイルは **ゼロックス／コラージュ調（粗い網点・破れ・ライムの蛍光）**。写真そのままではなく必ず加工されている。
- タイトルは太字17px前後、本文はグレー。**カード内に日付やタグを置いていない**＝情報を削って絵を立たせている。
- **注釈：本サイトの作品サムネも「加工前提」にすると、学生が撮ったバラバラの品質の写真が一気に統一される。** CSSの `filter` と `mix-blend-mode` だけでも近い効果が出せる（＝学生が高度な画像編集をしなくてよい）。これは運用上きわめて重要。

## C. techyscouts.com/services/web-design

**種別**：Web制作会社のサービス紹介ページ

### 実測データ

| 項目 | 実測値 |
|---|---|
| ディスプレイ書体 | **`Oi`**（Google Fonts・無料／極太レトロスラブ） |
| 本文書体 | **`Space Grotesk`**（Google Fonts・無料） |
| その他 | `Big Shoulders`（Google Fonts・無料）、`Le Murmure`（無料・Velvetyne） |
| 主要色 | `#BEBAB7`（本文グレー・813回）／**`#DBCC47`（マスタード）**／`#FFFFFF`／`#121212`（背景）／**`#F65F4E`（コーラル・CTA）** |
| H2 | 48px / weight 400 / **line-height 48px（＝1.0）** |

### 盗むべき構造パターン

**① 極太レトロ書体×ダーク背景（`techyscouts_01_hero.jpg`）**
- 見出しは `Oi` の全大文字、行間1.0でぎっしり4行。マスタード色。
- 背景は真っ黒ではなく **紺〜黒のグラデーション＋ノイズ**。これが「印刷物の紙」感を作っている。
- **注釈：`Oi` は無料で使える上に他サイトと被りにくい。** ただし**ラテン文字のみ・日本語グリフなし**。日本語見出しには使えないので、「英語の大見出し＋日本語の副見出し」という二段構えが必須になる（＝結果的に雑誌的になり、本件の方向性と合致する）。

**② コラージュ・マスコット**
- ハーフトーン処理された不気味かわいいキャラが、見出しの横に**背景から半分はみ出して**立っている。
- **注釈：ここは本件では「学生の作品そのもの」に置き換えるべき。** 外注イラストを増やすのではなく、豆腐ゲームPJ・実験再現PJ・詩タイピングPJの成果物を切り抜いて散らす。**制作コストゼロで、かつ「作品を見せる場」という目的にも合致する。**

**③ グラスモーフィズムのピル型ナビ**
- 半透明の黒いピルの中にナビ項目、右端に赤いグラデーションCTA（`Let's Talk`）。
- **注釈：本件のCTAは「スポンサーの方へ」または「入りたい人へ」。** 最優先読者がスポンサーなので、常時表示のCTAは1つに絞るべき。

### 弱点（真似しないほうがよい点）
- 本文色 `#BEBAB7` × 背景 `#121212` はコントラスト比 約9.6:1 で問題ないが、マスタード `#DBCC47` の細字を暗背景に使うと可読性が落ちる箇所がある。**大サイズのみに限定すること。**
- H2が `font-weight 400` で48px、しかもH1が存在しない。**見出し階層は自前で正しく組むこと。**

## D. 3サイトの共通項＝「今のアーティスティック」の最大公約数

| 共通項 | 3サイトでの現れ方 | 本件への適用 |
|---|---|---|
| **行間1.0の巨大見出し** | nexusmag 45px/45px、techyscouts 48px/48px | 見出しは `line-height: 0.95〜1.05`、`letter-spacing: -0.03em` |
| **色は3色以内＋蛍光1色** | 黒/白/#D7FF37、黒/グレー/#DBCC47+#F65F4E、黒/白/#999 | ベース2色＋アクセント1色に厳格に制限する |
| **枠線・影を使わない** | カードは地の色を変えるだけ | `box-shadow` 禁止、`border` は額装のみ |
| **写真は必ず加工** | コラージュ／ハーフトーン／全面動画 | 学生の写真品質差を加工で吸収する |
| **ラベルは小さく・本文は大きく** | 12px小ラベル ↔ 45px見出し | ジャンプ率を高くとる（4倍以上） |
| **無料フォントで十分成立している** | Switzer, Playfair, Rubik, DM Sans, Space Grotesk, Oi | **フォント費用は0円で今回のクオリティに到達可能** |
