## 調査を通じて確定した「本件の設計の芯」

以下は、複数の資料で独立に裏付けが取れた項目。**次に作成するデザイン大本資料の土台になる。**

1. **蛍光アクセントは「面」に使い、上に黒を載せる。白地の細字には絶対に使わない。**
   （04：ライムは白地で 1.17、黒地で 14.67。参考3サイト全てがこの使い方をしている）

2. **日本語は「ゆったり組む」。行間1.8〜2.0、字間0.07〜0.10em。ただし大見出しだけは詰める。**
   （03：武蔵野美大 lh 2.00 / ls 0.10em、JAGDA lh 1.80 / ls 0.071em の実測）

3. **`font-family` は「欧文書体 → 和文書体 → OS標準」の3段構え。**
   （07：武蔵野美大・JAGDA の両方が実際にこの順で書いている）

4. **モノスペースをラベル・日付・番号に使う。これが「今のエディトリアル」の指紋。**
   （02：70件中、複数書体を使うサイトの大半が Sans＋Serif＋Mono の三点セット）

5. **枠線・影を使わず、地の色を変えて面を分ける。**
   （01・02：参考3サイトと事例70件に共通）

6. **写真は必ず加工を通す。学生の撮影品質の差を、サイト側の仕組みで吸収する。**
   （04：CSSフィルタ案3種／06：ビルド時の自動最適化）

7. **画像が無いときのフォールバック（灰色地＋名前だけ）をデータ設計の段階で決めておく。**
   （07：武蔵野美大が実際にこの処理をしている）

8. **凝った入場演出は使うが、コンテンツは最初から見えている状態にする。**
   （05・06：nexusmag は3秒間まっ白だった。最優先読者がスポンサーである本件では致命的）

9. **日本の学生団体サイトには、デザイン面で参照に値する事例がほとんど存在しない。**
   （07：これは弱点ではなく好機。ちゃんと作るだけで圧倒的に目立つ）

10. **書体費用は0円で今回の目標品質に到達できる。**
    （02・03：参考サイトが使っていた Switzer / Space Grotesk / Oi / Playfair / Rubik / DM Sans は全て無料。日本語も Google Fonts に68書体ある）
