# 日本の「学生作品を大量に見せるサイト」分析

調査日：2026-08-09
本件（多数の学生作品＋団体紹介＋日本語）と**構造が同じ**日本語サイトを実ブラウザで分析した。
海外のエディトリアル事例（02フォルダ）は書体も言語も違うため、ここが実務上の最重要参照先になる。

---

## A. 武蔵野美術大学 卒業制作優秀作品集
https://selected.musabi.ac.jp/
スクリーンショット：`../screenshots/musabi_01_hero_jp_typography.jpg`, `musabi_02_category_grid.jpg`

### なぜ本件に近いか
- **多数の学生作品を、学科（＝カテゴリ）ごとに整理して見せる**という構造が、本件の「作品集 × 部活／PJ」と完全に同型。
- 読者は「受験生（＝新入生）」と「一般の人（＝外部）」。本件の読者構成とほぼ同じ。
- 日本語主体。

### 実測データ

| 項目 | 実測値 |
|---|---|
| 書体 | `a-otf-futo-go-b101-pr6n`（**太ゴB101**／モリサワ・Adobe Fonts）→ 游ゴシック → ヒラギノ角ゴ → メイリオ |
| 本文 | 16px / line-height **32px（2.00）** / letter-spacing **1.6px（0.10em）** |
| 学科名（H3） | 17px / line-height **42.5px（2.50）** / letter-spacing 1.6px |
| 色 | **黒（975箇所）と白（34箇所）の2色のみ** |
| 背景 | `#FFFFFF` |

### 盗むべき構造

**① 「囲み」で日本語見出しにリズムをつける**
```
武蔵野美術大学
卒業・修了制作 ( 優秀作品集 )    ← この部分だけ角丸の線で囲む
```
- 巨大な日本語見出しの**一部の単語だけを角丸の枠で囲む**。欧文の斜体やスモールキャップスに相当する「日本語で効く強調」。
- **注釈：日本語にはイタリックが無いため、強調手段が乏しい。この「囲み」は日本語エディトリアルの数少ない有効な武器で、実装は `border: 2px solid; border-radius: 999px; padding: .1em .6em;` の3行。本件でも必ず使う。**
  例：`北大心理ゼミ ( 作品集 )` / `大学生の溢れ出す妄想を ( 形にする )`

**② カテゴリ入口の3列グリッド（`musabi_02_category_grid.jpg`）**
```
┌─────────┐ ┌─────────┐ ┌─────────┐
│  写真    │ │  写真    │ │  写真    │   ← 16:9前後、角丸なし
└─────────┘ └─────────┘ └─────────┘
 空間演出デザイン学科  建築学科    基礎デザイン学科   ← 下に名前だけ
```
- カードの枠・影・背景色・説明文が**一切ない**。写真とラベルだけ。
- 写真がまだ無いカテゴリは、**グレー地に文字だけ**のブロックで代用している（`造形学部 通信教育課程` / `大学院 造形研究科`）。
- **注釈：これは本件の運用上、決定的に重要な発見。**
  部活やPJによっては「まだ良い写真がない」状態が必ず発生する。そのとき**灰色地＋名前だけのブロックに自動で切り替わる**設計にしておけば、穴が空いた見た目にならない。**この分岐はデータ設計の段階で決めておく必要がある**（画像フィールドが空のときのフォールバック）。

### 弱点
- ヒーローにカルーセル（自動送りスライダー）を使っている。**自動で動くスライダーは、見たい画像が消えるため一般にUX上不利**とされる。本件では採用しない方がよい。
- H1のテキストが空（画像で組んでいる）。SEOとスクリーンリーダーで不利。

## B. JAGDA（公益社団法人 日本グラフィックデザイン協会）
https://www.jagda.or.jp/

### なぜ参照するか
日本のグラフィックデザインの総本山。**「日本語でウェブを組むときの正解」の基準点**として、書体設定を確認する価値がある。

### 実測データ

| 項目 | 実測値 |
|---|---|
| 書体スタック | `aktiv-grotesk, a-otf-gothic-bbb-pr6n, 游ゴシック体, "Yu Gothic", YuGothic, "Hiragino Kaku Gothic ProN", Osaka, "ＭＳ Ｐゴシック", sans-serif` |
| 本文 | 14px / line-height **25.2px（1.80）** / letter-spacing **1px（0.071em）** |
| 記事見出し（H3） | 20px / line-height **40px（2.00）** / letter-spacing 1.5px（0.075em） |

### 盗むべき点

**和欧混植の書体スタックが、そのまま手本になる**
```
aktiv-grotesk , a-otf-gothic-bbb-pr6n , 游ゴシック体 , Yu Gothic , ヒラギノ角ゴ , ...
└欧文グロテスク  └中ゴシックBBB          └OS標準への段階的フォールバック
```
1. **先頭に欧文書体**（英数字だけこれで表示される）
2. **次に和文書体**（欧文書体が持たない文字＝日本語がこれで表示される）
3. **最後にOS標準の和文を複数**（Webフォント読み込み失敗時の保険）

- **注釈：本件の書体設定はこの3段構えをそのまま採用する。** 03フォルダの推奨案もこの形になっている。
- なお `ＭＳ Ｐゴシック` まで書いてあるのは、古い環境への配慮。本件は学生が対象なので、`Yu Gothic` / `Hiragino` までで十分。

## C. 日本の学生団体サイト全般について（所見）

検索した限り（[慶應義塾大学 学生団体](https://www.students.keio.ac.jp/com/life/extracurricular/club.html)、[芝浦工業大学](https://www.shibaura-it.ac.jp/campus_life/activity/index.html)、[ガクサー](https://gakucir.com/) 等）、**日本の学生団体の公式サイトで、デザイン面で参照に値する事例は見つからなかった。**

- 大学公式の部活紹介ページは一覧表・PDFが中心。
- 学生団体の個別サイトは、無料テンプレートかSNSリンク集がほとんど。

> **注釈：これは調査の失敗ではなく、本件にとって最も価値のある発見。**
> **「日本の学生団体サイトには、まともにデザインされたものがほとんど存在しない」**＝
> ちゃんと作るだけで、スポンサーの目には**圧倒的に本気の団体**として映る。
> 競合と比較されたときの相対的な優位が非常に大きい領域であり、
> Vision「北大で最も大量におもろいことが生まれる場所になる」の証明手段として、
> **サイトそのものが最初の「おもろいこと」になりうる。**

### 代わりに参照すべき国内の系統
1. **美大・芸大の卒展／作品集サイト**（上記A）— 構造が同型
2. **デザイン団体・ギャラリーのサイト**（上記B）— 日本語組版の基準
3. **芸術祭・ビエンナーレのサイト** — 「多数の企画を1つの世界観でまとめる」点が、イベント・部活・PJの3本柱を束ねる本件と同型

参考：全国の美術系大学の卒業制作展一覧（73校）
[【73校】2025年度 全国美術系大学・学部の卒業制作展一覧｜手羽イチロウ](https://note.com/tebaichiro/n/na95f416c6270)
→ **注釈：ここに列挙された73校の卒展サイトは、本件にとって最良の追加リサーチ先。** 次の工程で必要になれば、この中から数校を追加で分析できる。

## D. 本件が参照すべきでないもの（明示しておく）

| 対象 | 理由 |
|---|---|
| 大学公式サイト（北大含む） | 情報網羅が目的で、印象を作る設計になっていない。真似すると「大学の下部組織の広報ページ」に見えてしまい、団体の主体性が消える |
| 一般的な企業のコーポレートサイト | 信頼感は出るが、Mission「妄想を形にする」と完全に逆行する |
| ノーコードの汎用テンプレート | 「どこかで見たことがある」ことが最大の弱点。本件の目的（記憶に残る／見せたくなる）と直接矛盾する |
