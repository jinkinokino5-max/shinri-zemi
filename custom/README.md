# 独自ページの作り方

部活・PJ・イベント・作品は、**自分でデザインしたページ**をこのサイトに載せられます。

## 置き場所

```
custom/clubs/<部活の名前>/index.html      → https://（サイト）/clubs/<名前>/
custom/projects/<PJの名前>/index.html     → https://（サイト）/projects/<名前>/
custom/events/<イベント名>/index.html     → https://（サイト）/events/<名前>/
custom/works/<作品名>/index.html          → https://（サイト）/works/<名前>/
```

画像やCSSも**同じフォルダの中**に入れてください。

## ルール（守らないと公開されません）

| | ルール | なぜ |
|---|---|---|
| 1 | **JavaScriptは使えません**（HTMLとCSSだけ） | 同じサイトの中にあるため、将来ログイン機能を作ったときに、ここのJSがログイン情報を読めてしまう危険があるためです。**アニメーションもスクロール連動もCSSだけで書けます** |
| 2 | **外部サイトの画像やCSSを読み込まないでください** | 相手のサイトが消えると表示が崩れます。見た人のIPアドレスが外部に渡る問題もあります |
| 3 | **1つあたり10MBまで** | サイト全体が重くなるためです |
| 4 | `<h1>` を1つ入れてください | 読み上げソフトと検索エンジンのためです |
| 5 | 画像には `alt="説明"` を付けてください | 同上 |
| 6 | `<meta charset="UTF-8">` を入れてください | 無いと日本語が文字化けします |

**画面上部の「北大心理ゼミ ／ 一覧へ戻る」の帯は自動で入ります。**自分で書く必要はありません。

## 確認のしかた

提出前に、これを実行すると機械が見てくれます。

```
node scripts/check-custom-pages.mjs
```

そのあと**代表が内容を確認してから公開**されます。代表は次を見ます。

- 写っている人の許可は取れているか
- 拾い画像や他人の著作物が入っていないか
- 掲載ポリシーに反していないか

## ひな形

`custom/_example/index.html` をコピーして使ってください。
