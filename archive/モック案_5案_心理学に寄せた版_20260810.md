# トップページ モック案 5案（v1とは別作風）

作成日：2026-08-10
用途：既存の `draft/mock_top_v1.html`（新聞・額装エディトリアル）**とは異なる作風**の選択肢を並べ、方向性を1つ選ぶための資料。

---

## 0. 前提（5案すべてに共通して守るもの）

作風がどれだけ変わっても、以下は変えない。ここを揺らすと「別のサイト」ではなく「壊れたサイト」になる。

| # | 守るもの | 理由 |
|---|---|---|
| 0-1 | **Mission/Vision/Value は一字一句、原文どおり** | 大本資料 0-1 の絶対ルール。要約も「」囲みも禁止 |
| 0-2 | **不明な数字は空欄（`––`）のまま** | 年間の企画数・部員数・作品の制作年は未確定 |
| 0-3 | **本文のコントラスト比 4.5 以上** | 大本資料 4-1 の実測表に従う |
| 0-4 | **写真が1枚も無くても成立すること** | 現在、使える写真が確定していない |
| 0-5 | **「北海道大学の公認団体ではない」旨を置く場所を確保** | 非公認であるため。スポンサーへの誠実性に直結 |
| 0-6 | **`prefers-reduced-motion` で動きを止める** | 大本資料 6章 |

### 判明済みで、5案すべてが使える素材

- 設立：**2022年4月** ／ メンバー：**56名** ／ 部活：**7つ**（読書部・すこやか部・料理部・ふらっと部・言葉もてあそ部・研究室訪問部・ノンアルカクテル部）
- 現在進行中のPJ：**道東PJ**（2026年9月4〜6日）
- 連絡先・Instagram・X：あり
- ロゴ：**無い**（＝題字の文字組みが、そのまま団体の顔になる）

## 1. 既存 v1 の作風（比較の基準）

```
生成り地 #F4F1EA ／ 墨 #0E0E0E ／ 朱 #E8402A
極太のキルゴU題字＋明朝の見出し＋ゴシック本文
太い罫線で囲む「額装」レイアウト、新聞紙面の密度
スクロールで地が墨に反転する二層構造
```

**強み**：信頼感がある。密度が高いのでスポンサーへの説得力がある。写真ゼロでも成立する。
**弱み**：**堅い。**「妄想」「おもろい」という団体の言葉に対して、見た目が真面目すぎる。新歓で1年生が見て「楽しそう」と思うかは疑問が残る。

> **5案は、この「堅さ」をどの方向にほどくかの5通りである。**

## 案A ── 標本箱（INDEX CABINET）

### 一言
**心理学の実験カード／博物館の標本ラベル。**すべてを「採集された標本」として並べる。

### 見た目

```
┌──────────────────────────────────────────────┐
│ 北大心理ゼミ            EST. 2022  MEMBERS 56 │
├──────────────────────────────────────────────┤
│                                              │
│   大学生の溢れ出す妄想を形にする              │
│                                              │
├────────────┬────────────┬────────────────────┤
│ No.001     │ No.002     │ No.003             │
│ 読書部     │ すこやか部 │ 料理部             │
│ ──────     │ ──────     │ ──────             │
│ CLUB       │ CLUB       │ CLUB               │
│ 設立 ––    │ 設立 ––    │ 設立 ––            │
├────────────┼────────────┼────────────────────┤
│ No.004     │ No.005     │ No.006             │
│ ふらっと部 │言葉もてあそ部│ 研究室訪問部      │
└────────────┴────────────┴────────────────────┘
```

- 白に近い地。**1pxの細い罫線で仕切った格子**（v1の太い枠とは正反対）。
- 全項目に **通し番号（No.001…）** と **分類ラベル（CLUB / PROJECT / WORK）** を振る。
- 書体：等幅（Space Mono）でラベルと番号、本文はゴシック。**明朝を使わない。**
- 色：墨と生成りの2色＋朱は番号にだけ。**ほぼモノクロ。**
- 動き：ホバーでセルの地がすっと反転するだけ。**ページ遷移以外にアニメーションを入れない。**

### 強み
- **7部活・作品が増えるほど美しくなる。**格子は要素が多いほど効く。Vision「最も大量におもろいことが生まれる」を、数の見た目で証明できる。
- 写真ゼロでも**まったく寂しく見えない**（番号とラベルが絵になる）。
- 「心理学＝観察と記録」という団体名との接続が自然。
- **実装が最も速い。**CSS Grid ほぼ一発。今月中の公開に最も現実的。

### 弱み
- **冷たい。**淡々としている。「おもろい」より「几帳面」に見えるリスク。
- v1と同じ「静」の系統なので、**変化の幅は5案の中で最も小さい。**

### 向いている目的
スポンサー獲得 ◎ ／ 新歓 △ ／ 投稿したくなるか ○

## 案B ── 妄想ボード（SCATTER）

### 一言
**「溢れ出す妄想」を、そのまま画面上に散らかす。**Missionの直訳。

### 見た目

```
┌──────────────────────────────────────────────┐
│   ┌─────┐        大学生の                    │
│   │読書部│      溢れ出す妄想を               │
│   └─────┘   ┌──────────┐  形にする          │
│        ┌────┴─┐ 料理部  │      ┌──────┐     │
│  ┌─────┤ふらっと部     │      │道東PJ│     │
│  │言葉も│  └──────────┘      └──────┘     │
│  │てあそ部│    ┌───────────┐               │
│  └───────┘   │ すこやか部 │  ┌──────────┐ │
│      ┌──────────┐ └───────┘  │研究室訪問部│ │
│      │ノンアルカクテル部│       └──────────┘ │
│      └──────────┘   ↓ スクロールすると整列   │
└──────────────────────────────────────────────┘
```

- 部活・PJ・作品が**紙片として、それぞれ違う角度（±1〜4°）で重なって散乱**している。
- **スクロールすると、散らばった紙片がすーっと整列してグリッドになる。**これが仕掛けの中心。
  「妄想（散乱）→ 形にする（整列）」を、Missionの文字どおりに画面で演じる。
- 紙片は**掴んで動かせる**（任意。ドラッグ実装は工数が増える）。
- 色：生成り地＋紙片ごとに**淡い色（生成り／薄桃／薄黄／薄青）**。朱は見出しに。
- 書体：見出しに極太、紙片のラベルは手書き風ではなく**普通のゴシック**（手書き風フォントは安っぽくなるため使わない）。

### 強み
- **5案で最も「おもろい」。**Mission と Vision が、説明ではなく体験になっている。
- **新歓で圧倒的に強い。**1年生が最初の3秒で「なんか楽しそう」と思う。
- 学生が「自分のページを見せたくなる」という目的1に最も直結する。

### 弱み
- **スポンサー向けの真面目さが最も弱い。**ふざけて見えるリスクがある。
  → 対策：トップだけ散乱、団体紹介ページは整然、と使い分ける（v1の二層構造の考え方は流用できる）。
- **実装コストが5案で最大。**散乱の座標設計、重なり順、スクロール整列、モバイルでの破綻回避。今月中の公開だと**トップ1枚に絞る必要がある。**
- 回転した文字は読みにくい。角度は最大4°までに抑える設計上の制約が要る。

### 向いている目的
スポンサー獲得 △ ／ 新歓 ◎ ／ 投稿したくなるか ◎

- `writing-mode: vertical-rl` による**本物の縦組み**。ページ全体が**横スクロール**。
- 明朝の大きな縦組み＋細い縦罫。余白がとても広い。

### 弱み
- **横スクロールはスマホで嫌われることがある。**（スマホでは縦組みのまま縦スクロールに切り替える設計が必要＝分岐が増える）
- **情報量を詰め込めない。**スポンサー向けの実績・数字を並べるのに向かない。
- 古風に寄りすぎると「妄想」「おもろい」から離れる。**格調高いが、若くはない。**

### 向いている目的
スポンサー獲得 ○ ／ 新歓 △ ／ 投稿したくなるか ○ ／ **記憶に残るか ◎**

## 案E ── インクブロット（RORSCHACH）

### 一言
**ロールシャッハ・テストの染み。**左右対称のインクの形が、スクロールでゆっくり形を変える。

### 見た目

```
┌──────────────────────────────────────────────┐
│                                              │
│              ▄▄████▄▄                         │
│           ▄██████████▄                        │
│          ████▀    ▀████    ← 左右対称の染み   │
│           ▀██▄    ▄██▀       スクロールで変形 │
│             ████████                          │
│              ▀████▀                           │
│                                              │
│         大学生の溢れ出す妄想を形にする         │
│                                              │
│    ─────────────────────────────────────      │
│    この形が何に見えるかは、あなた次第です。    │
│    ※ この一文は団体の言葉ではなく、           │
│      サイト側のコピー（要・承認）             │
└──────────────────────────────────────────────┘
```

- SVGパスの左右対称の染み。**スクロール位置に応じてパスが変形**する（`animation-timeline: view()`）。
- 各部活・PJに**それぞれ固有の染みの形**を割り当てる。＝ **ロゴが無い問題を、これが解決する。**
- 色：生成り地に墨の染み。染みの中に文字を置かない（可読性のため）。朱は1箇所だけ。
- 書体：明朝。文字は控えめ、染みが主役。

### 強み
- **「心理」という団体名を、説明せずに視覚化できる唯一の案。**
- **ロゴが無いことが弱点でなくなる。**染みそのものが団体の視覚的アイデンティティになり、部活ごとの識別子にもなる。
- 「何に見えるかは人による」＝ 妄想は人それぞれ、という団体の思想と噛み合う。
- 写真が1枚も無くても、**画面に大きな絵がある。**5案で最も見た目が華やか。

### 弱み
- **ロールシャッハ・テストは、心理学の専門家からは「妥当性に議論のある投影法検査」として扱われる。**心理学系の団体が正面から掲げると、**分かっている人から軽く見られる可能性がある。**（→ 対策：「テスト」としてではなく、あくまで抽象的な模様として扱い、診断めいた文言を一切書かない）
- **染みの形をデザインする作業が発生する。**プログラムで生成すると汚くなりやすく、手で調整する時間が要る。
- 意味が抽象的で、**団体が何をしているかは伝わらない。**下の情報設計を別途しっかり作る必要がある。

### 向いている目的
スポンサー獲得 ○ ／ 新歓 ◎ ／ 投稿したくなるか ○ ／ **ロゴ代わりになるか ◎**

### 今月中の公開という制約を踏まえた見立て

- **今月中に全ページ公開したいなら：A か D。**どちらも構造が単純で、情報が足りていない今の状態にそのまま耐える。
- **見た目のインパクトを取りたいなら：E。**ただし染みの造形に時間が要る。
- **B は「トップページ1枚だけ」なら今月中に可能。**全ページとなると間に合わない。
- **C は最も差別化できるが、スマホ対応で工数が読みにくい。**

### 組み合わせるという選択肢

大本資料の**二層構造**（ページごとに作風を変える）を使えば、対立する要求を両立できる。

```
トップ・部活紹介   = B（散乱）または E（染み）  → 新歓・楽しさ
団体紹介・スポンサー = A（標本箱）または D（ログ） → 信頼・密度
作品集             = A（標本箱）               → 作品の色を邪魔しない
```

これは v1 が既に採っている考え方なので、設計としての無理はない。

## 3. 【追加要件】部活・PJが自分でデザインした紹介サイトを、同じドメインの下にぶら下げる

2026-08-10 に追加でいただいた要望。**結論：できます。**そして、これは**方向性の選び方を変える重要な要件**です。

### 3-1. URLの持ち方

```
https://（ドメイン）/                  ← 本サイト（トップ）
https://（ドメイン）/clubs/            ← 部活一覧（本サイトの作風）
https://（ドメイン）/clubs/dokusho/    ← 読書部が自分でデザインしたページ
https://（ドメイン）/clubs/ryori/      ← 料理部が自分でデザインしたページ
https://（ドメイン）/pj/doto/          ← 道東PJ
```

部活ごとに**フォルダを1つ**与え、その中は自由。GitHub Pages でも Cloudflare Pages でも、静的ファイルを置くだけで動きます。**追加費用はゼロ。**

### 3-2. これがデザイン方針に与える影響（重要）

各部活が好き勝手にデザインするなら、**本サイト側は「額縁」に徹したほうが良い。**
本サイトが主張しすぎると、子ページの作風とぶつかって全体が濁ります。

> **この観点では、案A（標本箱）が最も適しています。**
> 標本箱は「中身が何であれ、枠が支える」という構造そのものだからです。
> 7つの部活がそれぞれ違う色・違う書体でも、番号と罫線の格子に収まっていれば、散らかって見えません。
>
> 逆に、**案B（散乱）や案E（染み）は本サイト自体が強い絵を持つため、子ページと二重に主張することになります。**
> この要件を重視するなら、B・Eはトップページだけに留めるべきです。

### 3-3. デザインできない部活のための逃げ道

7部活すべてがHTMLを書けるとは限りません。**2段階を用意します。**

| ルート | 対象 | やること |
|---|---|---|
| **かんたん** | HTMLが書けない部活 | 用意された**テーマを選ぶ＋文章と写真を入れる**だけ。→ **この5案が、そのままテーマの候補になります** |
| **自由** | 作りたい部活 | `index.html` と `style.css` を自分で書いて提出。中身は完全に自由 |

### 3-4. 先に決めておくべきルール（⚠ 後から変えると全部作り直しになる）

| # | 項目 | 推奨 |
|---|---|---|
| R-1 | **JavaScript を許可するか** | ⚠ **当面は禁止（HTMLとCSSのみ）を強く推奨。**理由は下記 |
| R-2 | 共通の帯 | 各ページの**最上部に「北大心理ゼミ ／ 部活一覧へ戻る」の細い帯を必ず入れる**（これだけは団体側が管理し、部活は消せない）。迷子防止と、団体としての一体感 |
| R-3 | ファイルの置き場 | 画像もCSSも**自分のフォルダの外を参照しない。**外部CDNも使わない（リンク切れ・表示崩れの原因） |
| R-4 | 公開前の確認 | **誰か1人が必ず目を通してから公開。**掲載ポリシー（B-1〜B-5）違反、他人の写真、拾い画像のチェック |
| R-5 | 容量の上限 | 1部活あたり合計 **10MB程度** を目安に（写真の入れすぎ防止） |
| R-6 | 引き継ぎ | 部長が代替わりしたとき、**誰がそのフォルダを触れるか** |

> **R-1について。**同じドメインの下にあるページは、ブラウザから見て**同じ出所（オリジン）**として扱われます。
> つまり、**将来ログイン機能を作った後**に、部活ページに書かれたJavaScriptが、
> 本サイトのログイン情報を読み取れてしまう可能性があります。悪意がなくても、
> どこかからコピーしてきたコードにそういう挙動が混じることは実際にあります。
>
> **CSSだけでも、デザインの自由度はほとんど失われません。**
> アニメーション・スクロール連動・グラデーション・変形は、いま全部CSSでできます。
> JSを許可するのは、ログイン機能を作るときに改めて（サブドメインに分けるなどの対策とセットで）検討するのが安全です。
